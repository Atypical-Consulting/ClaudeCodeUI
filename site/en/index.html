3 tools · checks before installing

Claude Code UI drives the claude CLI you already have installed: it neither replaces nor bundles it. The CLI must be installed and signed in before the first launch.

Windows 10/11
-setup.exe or .msi · WebView2, already included in Windows 11
macOS
.dmg Apple Silicon (aarch64) or Intel (x64)
Linux x64
.AppImage or .deb · WebKitGTK 4.1

No .NET SDK or particular browser needed: the app bundles its own server and uses the system web view.

Not installed yet? The CLI installs with a single line:

# macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash
# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex

Then run claude once in a terminal to sign in. If the app cannot find it in the PATH, it shows a help screen instead of the start screen.

    Before you install

    Claude Code must already be working. The app launches your claude CLI: install it and sign in once in a terminal.

    Unsigned installers. Windows: SmartScreen shows "Windows protected your PC"; click "More info", then "Run anyway". macOS: Gatekeeper blocks the first launch; right-click the app, choose "Open", then confirm.

    Local only. The app's server listens on 127.0.0.1, protected by a token drawn at every launch, and stops when the window closes.

    8 tools · what the console does

    Several claude sessions run in parallel, each with its own folder and permission mode. The overview shows their state, last action and cost; the decision queue gathers everything waiting for your answer.

    Sessions and permissions in the docs

    When Claude wants to edit a file or run a command, the request opens in the inspector with the full diff or the exact command. Allow ⏎, Deny Del, or Whole session Shift ⏎ when the CLI offers a rule.

    Responding to permissions

    Below the input: the model (the list comes from the CLI), the effort level when the model supports it, Fast mode and Ultracode. Typing / opens the session commands, filtered as you type.

    The composer in detail

    Every subagent Claude starts gets its own line: open it to read what it writes and the tools it calls. With Ultracode, a turn becomes a multi-agent workflow, with its phases and a button to stop it.

    Following subagents

    The Worktrees page sorts each worktree as Safe, Needs review, Active or Orphaned, says why, and shows the git commands before running them. Never --force or branch -D: git itself refuses to delete an unmerged branch.

    Ranking and safeguards

    The Extensions page lists the session's MCP servers (connected, needing authentication, failed), plus its skills, agents and plugins. A toggle enables a server for the current folder, and a failed server restarts with "Retry".

    MCP extensions

    Five dark themes, Graphite, Encre, Ristretto, Mousse and High contrast, and an adjustable code size, remembered from one launch to the next. This page has them too: try the Theme picker.

    Themes

    Replies are rendered as Markdown with Markdig, raw HTML disabled: headings, tables, task lists, and code blocks highlighted by highlight.js with a copy button.

    Why no HTML

    The rest is in the documentation: installation, keyboard shortcuts, worktrees, known limitations.
