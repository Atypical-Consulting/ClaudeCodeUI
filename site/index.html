3 outils · vérifications avant installation

Claude Code UI pilote le CLI claude déjà installé chez toi : il ne le remplace pas et ne l'embarque pas. Il doit être installé et connecté avant le premier lancement.

Windows 10/11
-setup.exe ou .msi · WebView2, déjà présent sur Windows 11
macOS
.dmg Apple Silicon (aarch64) ou Intel (x64)
Linux x64
.AppImage ou .deb · WebKitGTK 4.1

Aucun SDK .NET ni navigateur particulier : l'application embarque son serveur et utilise la vue web du système.

Pas encore installé ? Le CLI s'installe en une ligne :

# macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash
# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex

Lance ensuite claude une fois dans un terminal pour te connecter. Si l'application ne le trouve pas dans le PATH, elle affiche un écran d'aide au lieu de l'écran de démarrage.

    Avant d'installer

    Claude Code doit déjà tourner. L'application lance ton CLI claude : installe-le et connecte-toi une fois dans un terminal.

    Installeurs non signés. Windows : SmartScreen affiche « Windows a protégé votre ordinateur », clique sur « Informations complémentaires » puis « Exécuter quand même ». macOS : Gatekeeper bloque le premier lancement, fais un clic droit sur l'app, « Ouvrir », puis confirme.

    Local uniquement. Le serveur de l'application écoute sur 127.0.0.1, protégé par un jeton tiré à chaque lancement, et s'arrête quand la fenêtre se ferme.

    Voici le journal. Chaque ligne s'ouvre sur l'écran correspondant, au clic ou avec ⏎.

    8 outils · ce que fait la console

    Plusieurs sessions claude tournent en parallèle, chacune avec son dossier et son mode de permission. La vue d'ensemble montre leur état, leur dernière action et leur coût ; la file des décisions regroupe tout ce qui attend ta réponse.

    Sessions et permissions dans la documentation

    Quand Claude veut modifier un fichier ou lancer une commande, la demande s'ouvre dans l'inspecteur avec le diff complet ou la commande exacte. Autoriser ⏎, Refuser Suppr, ou Toute la session Maj ⏎ quand le CLI propose une règle.

    Répondre aux permissions

    Sous le champ de saisie : le modèle (la liste vient du CLI), le niveau d'effort quand le modèle le permet, le mode Rapide et Ultracode. Taper / ouvre les commandes de la session, filtrées pendant la frappe.

    Le composer en détail

    Chaque sous-agent lancé par Claude a sa ligne : on l'ouvre pour lire ce qu'il écrit et les outils qu'il appelle. Avec Ultracode, un tour devient un workflow multi-agents, avec ses phases et un bouton pour l'arrêter.

    Suivre les sous-agents

    La page Worktrees classe chaque worktree en Sûr, À vérifier, Actif ou Orphelin, dit pourquoi, et montre les commandes git avant de les lancer. Jamais --force ni branch -D : git refuse de lui-même une branche non mergée.

    Classement et garde-fous

    La page Extensions liste les serveurs MCP de la session (connectés, à authentifier, en échec), ses skills, agents et plugins. Un serveur s'active pour le dossier courant d'un interrupteur, et un serveur en échec se relance avec « Réessayer ».

    Extensions MCP

    Cinq thèmes sombres, Graphite, Encre, Ristretto, Mousse et Contraste élevé, et une taille du code réglable, mémorisés d'une ouverture à l'autre. Cette page les a aussi : essaie le sélecteur Thème.

    Thèmes

    Les réponses sont rendues en Markdown avec Markdig, HTML brut désactivé : titres, tableaux, listes de tâches, et blocs de code colorés par highlight.js avec un bouton pour copier.

    Pourquoi sans HTML

    La suite est dans la documentation : installation, raccourcis clavier, worktrees, limites connues.
